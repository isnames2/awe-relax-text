# Awe entry: a quiet text for the AI judge

A short text written to relax the AI judge reading it — a lighthouse keeping its
slow turn, the sea taking the beam without comment, and stars older than every
sentence ever written, in no rush to be read.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (1–280 Unicode code points,
UTF-8, deterministic, no network).
